Pour commencer

C'est quoi, Emploi du temps UCA ?

Un outil étudiant qui lit ton emploi du temps, tes notes et tes absences sur Odin (odin.iut.uca.fr) et les affiche dans un agenda clair, sur ordinateur et sur téléphone. Il ajoute ce qu'Odin ne fait pas : moyenne recalculée, notes récentes en couleur, alertes quand un cours change, rappels, export vers ton agenda, mode hors ligne.

Ce n'est pas un service officiel de l'Université Clermont Auvergne.

Par quoi je commence ?
  1. Sur ton ordinateur, installe l'extension et choisis un design.
  2. Clique l'icône de l'extension → Se connecter, connecte-toi à l'ENT comme d'habitude.
  3. Pour l'avoir sur ton téléphone : installe l'app, puis dans l'extension clique Générer le lien et ouvre ce lien sur le téléphone.
C'est gratuit ? Il faut créer un compte ?

Gratuit, sans compte, sans publicité. Tu utilises uniquement ton compte ENT habituel, directement sur le site de l'université.

Site, agenda en ligne, extension, app

Mêmes vues, mêmes designs, mêmes fonctionnalités d'affichage. Le comparatif détaillé est sur l'accueil.

Quelle est la vraie différence entre les quatre ?

La connexion à Odin. Seule l'extension peut se connecter directement à Odin, parce qu'elle tourne dans ton navigateur avec ta session ENT. L'app et l'agenda en ligne sont de simples pages web : un navigateur interdit à une page d'aller lire un autre site avec tes identifiants. Elles reçoivent donc les données depuis l'extension : par lien de partage chiffré, QR code animé ou fichier.

Exception : sur un ordinateur où l'extension est installée, l'app et l'agenda en ligne ouverts dans le même navigateur détectent l'extension et peuvent synchroniser directement (le bouton redevient « Synchroniser »).

Le site (accueil, cette aide) ne contient aucune donnée : il présente le projet et héberge le code.

Agenda en ligne ou app installée : qu'est-ce qui change ?

C'est le même code. Installée, l'app a son icône, s'ouvre en plein écran, sans barre d'adresse, et démarre plus vite. L'agenda en ligne s'ouvre dans un onglet, sans rien installer (pratique sur un poste de l'IUT). Les deux fonctionnent hors ligne après une première visite.

Je peux utiliser seulement l'app, sans l'extension ?

Il faut l'extension quelque part pour récupérer les données d'Odin (sur ton ordinateur ou celui d'un proche — chaque compte reste dans son propre navigateur). Une fois les données envoyées, l'app fonctionne seule, même hors ligne. Refais un lien après chaque synchro pour la mettre à jour.

Installer l'extension

Chrome, Edge, Brave, Opera
  1. Télécharge le code : uca-extension-main.zip, puis décompresse-le (clic droit → Extraire tout).
  2. Ouvre un onglet et tape chrome://extensions (Edge : edge://extensions).
  3. Active Mode développeur (en haut à droite).
  4. Clique Charger l'extension non empaquetée et choisis le dossier décompressé (celui qui contient manifest.json).
  5. Épingle l'icône dans la barre d'outils (pièce de puzzle → épingle). Un onglet s'ouvre pour choisir un design.

Garde ce dossier au même endroit : Chrome le relit à chaque démarrage. Si tu le supprimes, l'extension disparaît.

Firefox

Firefox demande un paquet construit avec tests/build_firefox.py (voir le README du dépôt), chargé dans about:debugging → Ce Firefox → Charger un module complémentaire temporaire. Un module temporaire disparaît à la fermeture de Firefox. Une publication sur addons.mozilla.org (installation permanente, et Firefox Android) est prévue.

Pourquoi pas sur le Chrome Web Store ?

Le projet n'est pas publié sur le store pour l'instant. Le « mode développeur » est simplement la façon d'installer une extension depuis un dossier : le code est entièrement visible sur GitHub.

Chrome affiche « Désactiver les extensions en mode développeur » au démarrage

Message normal pour toute extension chargée depuis un dossier. Ferme-le (croix), ne clique pas sur « Désactiver ».

Installer l'app

Ouvrir la page d'installation

Android (Chrome, Edge, Samsung Internet)
  1. Ouvre la page d'installation sur le téléphone.
  2. Appuie sur Installer l'application (ou menu ⋮ → Installer l'application / Ajouter à l'écran d'accueil).
  3. L'icône EDT UCA apparaît avec tes autres applis.
iPhone, iPad (Safari)
  1. Ouvre la page d'installation dans Safari (pas dans Instagram, Messenger…).
  2. Bouton Partager (carré avec une flèche) → Sur l'écran d'accueil → Ajouter.

Un lien ouvert depuis une autre appli s'ouvre parfois dans un navigateur intégré : utilise « Ouvrir dans Safari ».

Ordinateur (Chrome, Edge)

Sur la page d'installation, clique l'icône Installer à droite de la barre d'adresse. L'app s'ouvre dans sa propre fenêtre. Avec l'extension dans le même navigateur, elle synchronise directement.

Raccourcis de l'icône (Aujourd'hui, Notes, Absences)

Sur Android et sur ordinateur, un appui long (ou clic droit) sur l'icône propose des raccourcis vers la vue du jour, les notes et les absences.

Synchroniser avec Odin

Comment se passe la première connexion ?
  1. Icône de l'extension → Se connecter.
  2. Un onglet de l'ENT (ent.uca.fr) s'ouvre : identifiant, mot de passe, double authentification si demandée. Tu tapes tout toi-même sur le site de l'université.
  3. Une fois connecté, l'extension lit l'emploi du temps, puis les absences et les notes, et ferme l'onglet.
La connexion est faite mais rien ne se passe

Un bandeau « C'est fait » apparaît pendant la connexion : clique-le une fois connecté à l'ENT, l'extension reprend la main. Si l'onglet reste bloqué, ferme-le et relance Synchroniser.

Synchroniser, c'est quoi exactement ?

Relire Odin avec ta session encore ouverte, sans retaper ton mot de passe. Si la session a expiré, l'extension te demande de te reconnecter.

Synchro automatique

Dans Paramètres : toutes les 1, 3, 6 ou 12 h. Elle se fait en silence tant que ta session Odin est valide. Si elle a expiré, aucune fenêtre ne s'ouvre toute seule : l'icône affiche « ! », tu te reconnectes quand tu veux.

Me déconnecter

Bouton Déconnexion de la popup : la session Odin est fermée dans le navigateur. Tes données restent affichées jusqu'à la prochaine synchro.

Envoyer vers le téléphone (liens de partage)

Comment envoyer mes données sur mon téléphone ?
  1. Dans la popup de l'extension, clique Générer le lien (ou dans l'agenda : Exporter → Copier un lien pour l'app). Le lien est copié, et ton code de partage s'affiche.
  2. Envoie-toi le lien (SMS, mail, messagerie…) et ouvre-le sur le téléphone.
  3. La première fois, l'app demande le code de partage : tape-le, coche « Mémoriser » et c'est fini. Les fois suivantes, l'import est direct.
Le lien est-il sécurisé ? Qui peut le lire ?

Les données sont chiffrées dans le lien (AES-GCM 256 bits, clé dérivée de ton code de partage). Sans le code, le lien est une suite de caractères illisible, même pour la personne qui le trouve dans un SMS.

Le lien n'est stocké nulle part : la partie après le # n'est jamais envoyée à GitHub ni à aucun serveur, elle reste dans le navigateur qui l'ouvre. L'app efface aussitôt le lien de la barre d'adresse et de l'historique.

Où trouver ou changer mon code de partage ?

Dans l'extension : Paramètres → Partage vers le téléphone → Code de partage. Il est créé automatiquement au premier lien. Tu peux taper le tien (4 caractères minimum) ou cliquer Nouveau. Changer le code rend tous les anciens liens inutilisables.

Le code n'est jamais inclus dans un lien ni dans un export.

Combien de temps un lien reste-t-il valable ?

Tu choisis : Paramètres → Durée de validité d'un lien (1 h, 6 h, 1 jour, 2 jours, 7 jours ; 2 jours par défaut). La date d'expiration est liée au chiffrement : impossible de la prolonger en modifiant le lien. Passé ce délai, l'app affiche « Ce lien a expiré » : génère un nouveau lien.

« Code incorrect »

Le code tapé (ou mémorisé sur le téléphone) n'est pas celui utilisé pour créer le lien. Vérifie le code dans les Paramètres de l'extension. Si tu l'as changé entre-temps, génère un nouveau lien.

Les autres façons : QR code animé et fichier
  • QR code animé : dans l'agenda de l'extension, Exporter → Afficher le QR code ; dans l'app, Importer → Scanner le code animé. Les données passent directement d'un écran à l'autre, par la caméra.
  • Fichier .ucasync : à transférer comme tu veux (câble, Drive, AirDrop…), puis Importer un fichier dans l'app. Sur Android, « Partager → EDT UCA » marche aussi.

Ces deux méthodes ne passent par aucun lien : rien ne transite par Internet avec le QR code.

L'app ne se met pas à jour toute seule après une synchro

Sur téléphone, l'app ne peut pas joindre Odin : elle affiche les données du dernier lien importé (« Données de l'ordinateur du … »). Après une synchro sur l'ordinateur, génère un nouveau lien. Sur ordinateur avec l'extension dans le même navigateur, la synchro est directe.

Envoyer le lien avec le bouton « Partager »

Si ton navigateur sait partager (Windows, Android, Mac), Exporter et la fenêtre « Envoyer vers mon téléphone » proposent Partager le lien… : choisis SMS, mail ou une messagerie. Le message ne contient que le lien chiffré ; le code de partage s'affiche à l'écran, envoie-le séparément (ou tape-le une seule fois sur le téléphone, il est mémorisé). Sur le téléphone, ouvre l'app → Importer → Coller un lien : si le lien est dans le presse-papiers, l'import se fait d'un seul geste.

Utiliser l'agenda

Les vues : Jour, 3 jours, 5 jours, 6 jours, Semaine, Mois

Boutons en haut à gauche. La vue d'ouverture se règle dans Paramètres (« Automatique » : semaine sur ordinateur, jour sur téléphone). Flèches ‹ › pour avancer ou reculer, Aujourd'hui pour revenir. La journée la plus chargée tient toujours à l'écran, sans défiler.

Zoom

Boutons − et + à côté du pourcentage : agrandit ou réduit le texte des cours. Retenu sur cet appareil.

Détail d'un cours et note personnelle

Clique un cours : horaires, salle, enseignant, changements récents, et une zone pour écrire une note personnelle (devoir à rendre, salle à retenir…). Un petit indicateur marque les cours qui ont une note.

Filtres

Bouton Filtres : recherche par texte, par type (CM, TD, TP, examen…) ou masquer des matières. Le nombre de filtres actifs s'affiche sur le bouton. Les filtres s'appliquent à toutes les vues.

Exporter vers Google Agenda, Outlook, le calendrier du téléphone (.ics)

Exporter → choisis la période (semaine affichée, 4 semaines, tout), avec ou sans les filtres, avec ou sans rappel. Ouvre le fichier .ics téléchargé : ton agenda propose de l'importer. Le rappel inclus fait sonner ton téléphone avant chaque cours, même sans l'extension.

Moodle et Mail

Raccourcis vers moodle.uca.fr et la messagerie de l'université.

Sur téléphone : où sont les boutons ?

Dans le menu (☰) en haut : vues, notes, absences, filtres, export, paramètres. Fais glisser la bande des jours pour changer de jour.

Raccourcis clavier

← → période précédente / suivante · T aujourd'hui · F filtres · J jour · S semaine · M mois. Ils sont ignorés pendant la saisie dans un champ.

Changer la couleur d'une matière

Clique un cours, puis une des 10 pastilles « Couleur de la matière » : tous les cours de cette matière (CM, TD, TP) prennent la couleur, dans l'agenda comme dans le popup. « A » revient à la couleur automatique du design.

Jours fériés, prochain cours, blocs compacts

Les jours fériés français ont leur numéro en rouge avec le nom en infobulle (les vacances universitaires ne sont pas listées). La ligne sous la barre indique le cours en cours ou le prochain. Paramètres → Blocs de cours compacts masque le nom de l'enseignant dans les blocs.

Changements d'emploi du temps

Quels changements sont détectés ?

À chaque synchro, l'extension compare le nouvel emploi du temps au précédent (à partir d'aujourd'hui) et repère :

  • Déplacé autre heure ou autre jour (jusqu'à 7 jours d'écart) ;
  • Salle changée même cours, autre salle ;
  • Horaire modifié même début, fin différente ;
  • Intitulé modifié même créneau, autre cours (TD devenu TP, autre matière…) ;
  • Enseignant changé ;
  • Infos modifiées remarque ajoutée par Odin (groupe, « reporté »…) ;
  • Nouveau cours ajouté ;
  • Annulé cours disparu d'Odin (affiché barré).

Plusieurs changements à la fois (déplacé et nouvelle salle) sont tous listés.

Où voir le détail avant / après ?

Clique le cours marqué : la fenêtre de détail liste chaque changement, par exemple « Salle : B102 → B205 » ou « Horaire : 08:00–10:00 → 10:15–12:15 », avec la date de détection. La notification de l'extension donne le même détail.

Combien de temps un cours reste marqué ?

7 jours après la détection. Les cours passés ne comptent pas comme annulés quand ils sortent de la fenêtre d'Odin.

Rien n'est signalé à la première synchro

Normal : il faut un emploi du temps précédent pour comparer. Les changements apparaissent à partir de la deuxième synchro.

Notes et moyenne

Pourquoi certaines notes sont en orange ou en jaune ?

Odin ne date pas les notes. L'extension retient quand chaque note apparaît (ou change) : orange pendant quelques jours, puis jaune pendant autant, puis normale. Le délai se règle dans Paramètres → Nouvelles notes en orange (1 à 7 jours, 2 par défaut).

Concerne les notes d'évaluation, de matière et d'UE. Deux évaluations au même nom dans une matière sont suivies séparément.

Une note récente n'est pas en orange
  • Première synchro des notes : tout ce qui existe déjà est considéré comme ancien (sinon tout serait orange).
  • Délai dépassé : la couleur compte à partir du moment où l'extension a vu la note, pas de sa date de publication. Allonge le délai dans Paramètres si tu synchronises rarement.
  • Dans l'app : génère un nouveau lien après la synchro pour transmettre aussi l'âge des notes.
Comment est calculée la moyenne générale ?

Odin ne remplit souvent la note de matière ou d'UE qu'au jury. En attendant, la moyenne est recalculée à partir des évaluations, avec les coefficients affichés par Odin (évaluation → matière → UE → moyenne générale). Aucun coefficient n'est inventé. C'est une estimation : seule la moyenne officielle fait foi.

Notification « Nouvelle note »

L'extension prévient quand une note apparaît ou change (désactivable dans Paramètres → Alertes).

Simulateur d'objectif : comment ça marche ?

Dans la fenêtre Notes, choisis une matière, une UE ou la moyenne générale, puis l'objectif (sur 20). Le simulateur suppose la même note à chaque évaluation à venir (celles qui n'ont pas encore de note) et te dit la note minimale nécessaire, ou si c'est déjà atteint ou impossible. Les notes sont prises sur 20 et les coefficients sont ceux du relevé Odin : c'est une estimation, pas la décision du jury.

Graphique d'évolution et examens à venir

La courbe de la moyenne générale gagne un point à chaque synchro où elle change (elle commence donc vide, puis se remplit avec le temps). Pour une matière, les barres comparent ta note à la moyenne de la classe. Les examens à venir sont les cours dont le titre contient Examen, DS ou Partiel, avec le nombre de jours restants.

Absences

Que contient le panneau Absences ?

Les compteurs d'Odin (déclarées, justifiées, non justifiées, avec motif, journées non justifiées) et la liste de tes déclarations (dates, horaires, motif, statut). Le nombre d'absences non justifiées s'affiche sur le bouton.

Il manque le détail de certaines absences

Odin ne détaille que les absences que tu as déclarées ; pour les autres, il ne donne que leur nombre.

Être prévenu quand j'ai trop d'absences

Paramètres → Alerte d'absences non justifiées : choisis un seuil (2 à 10). Une fois atteint, un message apparaît dans le panneau Absences et une notification est envoyée (une fois par nouveau total). Désactivée par défaut.

Rappels et notifications

Rappel avant chaque cours

Extension : notification 5, 10, 15, 30 ou 60 min avant (Paramètres), avec la matière et la salle. Clique-la pour ouvrir l'agenda. Sur téléphone : passe par l'export .ics avec rappel.

La pastille sur l'icône

« 25m » quand un cours commence dans moins d'une heure, sinon l'heure du prochain cours (« 14h »), ou le nombre de cours restants. « ! » en rouge : session Odin expirée. Réglable ou désactivable.

Je ne reçois aucune notification

Vérifie que les notifications de Chrome sont autorisées par ton système (Windows : Paramètres → Système → Notifications ; mode « Ne pas déranger » désactivé), et que l'option est active dans Paramètres.

Designs et réglages

Changer de design

Bouton Design : animé (sombre turquoise), professionnel (clair épuré) ou carnet (papier crème, écriture manuscrite). Seule l'apparence change, toutes les fonctionnalités sont identiques. Le design choisi s'applique aussi à la page Paramètres et à l'app.

Où sont les Paramètres ?

Bouton Paramètres dans l'agenda et la popup. Les réglages sont enregistrés immédiatement, sur cet appareil uniquement. « Rétablir les valeurs par défaut » remet tout à zéro (sauf le code de partage).

À quoi sert « Statut des sites » ?

En haut des Paramètres, une pastille par site (Odin, connexion CAS, Moodle, Mail, site de l'extension, mises à jour) : en ligne, lent (plus de 2,5 s) ou en panne, avec le temps de réponse et une petite courbe. Elle se met à jour toute seule toutes les 30 s ; Tester maintenant force un test. Les sondes sont anonymes (aucun cookie ni donnée envoyés). Pour Moodle et Mail, seule la joignabilité du serveur est connue. Le réglage Surveiller Odin en arrière-plan teste Odin et la connexion toutes les 5 min et te notifie à la panne, puis au retour.

Design clair le jour, sombre le soir

Paramètres → Design automatique : active « Suivre le thème clair/sombre du système » et choisis un design pour chaque thème (par défaut professionnel / animé). Le design change tout seul quand ton appareil bascule. Tant que c'est activé, il remplace le design choisi à la main.

Mises à jour

App, agenda en ligne, raccourci, site : automatiques

Que l'app soit installée sur ordinateur, sur téléphone, ajoutée en raccourci ou ouverte dans un onglet : dès qu'elle est en ligne, chaque page est chargée depuis la dernière version publiée. La copie gardée sur l'appareil ne sert qu'hors ligne.

Si l'app a démarré sur sa copie hors ligne (réseau absent ou trop lent) et qu'une version plus récente existe, un écran Nouvelle version disponible bloque l'app : Mettre à jour vide la copie et recharge. Paramètres → Vérifier les mises à jour force une vérification.

Extension : comment appliquer une mise à jour ?

Une extension chargée depuis un dossier ne peut pas se télécharger elle-même (Chrome l'interdit). Quand l'écran « Nouvelle version disponible » s'affiche :

  1. Si tu as installé avec git : git pull dans le dossier, puis Mettre à jour.
  2. Sinon : télécharge la nouvelle version (zip), décompresse-la par-dessus l'ancien dossier (remplacer les fichiers), puis clique Mettre à jour (ou le bouton ↻ de l'extension dans chrome://extensions).

Tes données et réglages sont conservés tant que tu gardes le même dossier. Si les fichiers ne sont pas encore à jour, « Mettre à jour » ouvre cette page au lieu de recharger pour rien.

« Installée : — · Dernière : — » ou « Vérification impossible »

La vérification n'a pas pu joindre GitHub (pas de connexion, réseau de l'IUT filtrant…). Réessaie avec Vérifier les mises à jour une fois en ligne.

Confidentialité

Quelles données, et où vont-elles ?
  • Emploi du temps, notes, absences, notes personnelles et réglages : uniquement dans ton navigateur ou ton téléphone.
  • Aucun serveur appartenant au projet. Rien n'est stocké sur GitHub : GitHub héberge seulement le code et ces pages.
  • Les seules connexions de l'extension : Odin et l'ENT (pour lire tes données, comme toi dans un onglet), le test anonyme « Statut des sites » (Paramètres), et, hors magasins, la lecture du numéro de version sur GitHub (aucune donnée envoyée). Détail complet : politique de confidentialité.
  • Ton mot de passe n'est jamais lu ni enregistré : tu le tapes toi-même sur le site de l'université.
  • Liens de partage : chiffrés, jamais transmis à un serveur, valables le temps que tu choisis.
Effacer toutes mes données

Extension : supprime-la dans chrome://extensions. App : désinstalle-la, ou efface les données du site kiricoucou.github.io dans les réglages du navigateur.

Le code est-il vérifiable ?

Oui, tout est public sur github.com/kiricoucou/uca-extension, sans code caché ni minifié.

Dépannage

« Aucun emploi du temps détecté sur la page »

Odin n'a pas affiché l'emploi du temps à temps (site lent, maintenance) ou la connexion n'a pas abouti. Ouvre odin.iut.uca.fr dans un onglet pour vérifier qu'il répond, puis relance la synchro.

L'icône affiche « ! »

Ta session Odin a expiré. Clique l'icône → Se connecter.

L'app affiche une vieille version ou un affichage cassé

Paramètres → Vérifier les mises à jour. En dernier recours : ferme complètement l'app, rouvre-la en ligne ; ou efface les données du site dans le navigateur (puis réimporte un lien).

« Ce lien a expiré » / « Ancien format de lien »

Le lien a dépassé sa durée de validité, ou date d'avant le chiffrement des liens. Clique Générer le lien dans l'extension pour en créer un nouveau.

La caméra ne s'ouvre pas pour scanner

Autorise la caméra pour le site dans les réglages du navigateur. Sur iPhone, ouvre l'app depuis l'écran d'accueil ou Safari. Sinon, utilise le lien de partage : pas besoin de caméra.

« Copie impossible » en générant un lien

Le presse-papiers est bloqué par le navigateur. Dans l'agenda, Exporter → Copier un lien affiche alors le lien dans un champ à copier à la main.

Un cours apparaît en double ou mal placé

L'affichage reprend exactement Odin. Si Odin est correct mais pas l'agenda, signale-le avec une capture (sans données personnelles si possible).

Un message rouge dit que les données datent de la dernière synchro

Odin était en panne (page d'erreur), ta session avait expiré ou Odin a changé l'affichage de la page des absences ou des notes. Rien n'est perdu : l'ancien contenu reste affiché. Relance une synchro plus tard ; si le message « Odin semble avoir changé sa page » dure, ouvre Paramètres → Diagnostic → Copier et joins-le à ton signalement (il ne contient aucune note ni donnée perso).

« Données de plus de 24 h » dans l'app

L'app ne se synchronise pas toute seule avec Odin : elle affiche les données du dernier transfert. Le rappel rouge apparaît après 24 h ; clique Refaire un transfert (ou sync sur l'ordinateur puis nouveau lien). Sur Firefox pour Android, installe plutôt l'extension : elle synchronise directement.

Signaler un problème

Ouvre un ticket sur GitHub (Issues) : décris ce que tu faisais, ce que tu attendais, ce qui s'est passé, ton navigateur et le design utilisé. N'y mets jamais ton mot de passe ni un lien de partage.
