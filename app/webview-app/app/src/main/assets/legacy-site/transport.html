    Comment ça marche ?
    1. Choisissez l'arrêt où vous allez monter. Plusieurs arrêts peuvent avoir des noms proches : vérifiez le nom complet et les lignes.
    2. La page demande les prochains passages de cet arrêt au serveur de T2C (api.t2c.fr), directement ou par l'extension si elle est installée. La demande contient le code de l'arrêt et l'heure.
    3. Les passages sont classés par ligne et par direction, avec jusqu'à trois horaires chacun. Vérifiez la direction avant de monter.
    4. Tant que la page est visible, l'arrêt affiché est redemandé toutes les 30 secondes.
    5. Vos favoris restent dans ce navigateur ou cette application, sur cet appareil.
    6. Si le serveur ne répond pas, la page n'affiche aucun horaire de remplacement. Consultez alors le site officiel.
