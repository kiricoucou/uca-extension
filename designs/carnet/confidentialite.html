Politique de confidentialité

Emploi du temps UCA (non officiel) — extension de navigateur (Chrome, Edge, Firefox), site et application web installable.

Outil non officiel, non affilié à l'Université Clermont Auvergne (UCA). Développé de façon indépendante pour faciliter la lecture de son propre emploi du temps, de ses absences et de ses notes déjà accessibles sur Odin (ent.uca.fr / odin.iut.uca.fr).

En bref

Il n'existe aucun serveur derrière ces outils, aucun compte, aucune publicité, aucune télémétrie, aucun traceur. Tes cours, tes notes et tes absences ne sont jamais envoyés à l'éditeur de l'outil ni à un tiers. Ils restent dans ton navigateur, sur ton appareil.

Où sont stockées tes données

  • Extension : dans le stockage local de ton profil navigateur (chrome.storage.local ou l'équivalent Firefox) : emploi du temps, notes personnelles, absences, relevé de notes, réglages, couleurs de matières.
  • Site et application web : dans le localStorage de ton navigateur (ou celui de l'application installée), sur ton appareil. Les pages du site sont servies par GitHub Pages ; elles ne reçoivent jamais tes données.

Connexion UCA (CAS / Odin)

Pour récupérer tes données, l'extension ouvre la page de connexion officielle de l'UCA (ent.uca.fr), exactement comme si tu allais directement sur Odin. Ton identifiant et ton mot de passe sont saisis sur le site de l'UCA : ils ne sont jamais lus, stockés ni transmis par l'extension. Une fois connecté, elle lit le contenu des pages que ta propre session a le droit de voir (emploi du temps, absences, notes) et l'affiche dans une interface plus pratique.

Toutes les connexions réseau

  • ent.uca.fr et odin.iut.uca.fr : connexion et lecture de tes pages, avec ta session.
  • Statut des sites (Paramètres) : requête de lecture anonyme (sans cookie ni donnée) vers odin.iut.uca.fr, ent.uca.fr, moodle.uca.fr, mail.uca.fr, kiricoucou.github.io et raw.githubusercontent.com, pour savoir si ces sites répondent. Uniquement quand la page Paramètres est ouverte, ou si tu actives la surveillance en arrière-plan.
  • Mises à jour (paquet de développement seulement) : lecture du fichier public manifest.json sur raw.githubusercontent.com pour connaître la dernière version. Les paquets des magasins (addons.mozilla.org, Chrome Web Store) ne le font pas : le magasin met à jour tout seul.
  • Aucune autre requête. Aucun service d'analyse, aucune police ou bibliothèque chargée depuis Internet.

Partage vers le téléphone

Le bouton « Envoyer vers le téléphone » crée un lien dont les données sont chiffrées (AES-GCM 256, clé dérivée du code de partage choisi par toi) et placées après le # de l'adresse : cette partie n'est jamais envoyée dans une requête HTTP, GitHub Pages ne la voit pas. Sans le code de partage, le lien est illisible ; il expire après la durée que tu choisis (1 heure à 7 jours). Tu décides à qui tu envoies le lien.

Permissions demandées

  • storage : enregistrer tes données et réglages sur ton appareil.
  • scripting + accès à ent.uca.fr et odin.iut.uca.fr : ouvrir ces pages en arrière-plan et lire leur texte.
  • cookies : lire la durée restante de ta session UCA et, quand tu cliques sur « Déconnexion », supprimer les cookies de ent.uca.fr et odin.iut.uca.fr uniquement.
  • alarms : rappels de cours, synchronisation automatique, pastille de l'icône.
  • notifications : rappels et alertes (désactivables dans Paramètres). Absente de Firefox pour Android.
  • Script sur kiricoucou.github.io/uca-extension/ : relier le site/app à l'extension (bouton « Synchroniser » du site). Il ne transmet rien d'autre.

Suppression de tes données

Paramètres → Données → « Réinitialiser l'agenda » efface cours, notes, absences et relevé (annulable 10 minutes). Désinstaller l'extension, ou effacer les données du site dans les réglages du navigateur, supprime tout immédiatement : rien n'est conservé ailleurs.

Code source et responsabilité

Le code est lisible tel quel (aucune minification) dans le dépôt github.com/kiricoucou/uca-extension. Ces outils sont développés pour un usage personnel et fournis sans garantie ; l'UCA peut modifier Odin à tout moment. Une question ou un problème : ouvre un ticket sur le dépôt.
