Ajouter l'extension en 2 minutes

Elle n'est pas (encore) sur le Chrome Web Store : on la charge à la main, une seule fois.

Télécharge et décompresse

  1. Clique sur « Télécharger le ZIP » (en haut de cette page). Le fichier uca-extension-chrome.zip arrive dans ton dossier Téléchargements.
  2. Ouvre ce dossier, fais un clic droit sur le fichier → « Extraire tout… » → « Extraire » (Mac : double-clic).
  3. Tu obtiens un dossier, par exemple uca-extension-chrome, qui contient directement manifest.json. Ne le supprime pas et ne le déplace plus : Chrome le lit depuis cet endroit tant que l'extension est installée.

Active le mode développeur

  1. Ouvre un nouvel onglet, tape chrome://extensions (Edge : edge://extensions) puis Entrée.
  2. En haut à droite, active l'interrupteur « Mode développeur ».
  3. Une barre de trois boutons apparaît : « Charger l'extension non empaquetée », « Empaqueter l'extension » et « Mettre à jour ». Tu vas utiliser le premier.

Charge le dossier

  1. Clique sur « Charger l'extension non empaquetée ».
  2. Dans la fenêtre « Sélectionner le répertoire de l'extension », ouvre Téléchargements et sélectionne le dossier décompressé (pas le fichier .zip).
  3. Clique sur « Sélectionner un dossier ». L'extension « Emploi du temps UCA » apparaît dans la liste.
  4. Clique sur l'icône puzzle de la barre d'outils, puis sur l'épingle à côté de l'extension pour l'avoir toujours sous la main.

Questions

Est-ce que le ZIP contient mes données ?

Non. Le ZIP est généré depuis le code public : cours, notes et identifiants n'existent que dans le navigateur de chacun. Chaque personne démarre à vide et se connecte avec son propre compte UCA.

Et mon mot de passe ?

Il est tapé sur la vraie page de connexion de l'UCA (CAS). L'extension ne le voit pas et ne l'enregistre pas.

Chrome affiche « Désactiver les extensions en mode développeur »

Message normal pour toute extension chargée à la main : ferme-le sans désactiver. Ne déplace ni ne supprime le dossier décompressé, sinon l'extension disparaît.

Comment mettre à jour ?

Le plus simple : télécharge maj-extension.bat (sans droits administrateur), mets-le dans le dossier de l'extension et double-clique : il télécharge la dernière version, remplace les fichiers, puis il te reste à cliquer « Recharger » dans chrome://extensions (ou à attendre la vérification automatique). À la main : retélécharge le ZIP, remplace le contenu du dossier et recharge. L'extension te prévient quand une nouvelle version existe. Le script est ajouté dans le ZIP, à côté de manifest.json.

Linux : installation automatique sans sudo

Télécharge install-linux.sh puis lance bash install-linux.sh (ou, en une ligne : curl -fsSLO https://kiricoucou.github.io/uca-extension/extension/install-linux.sh && bash install-linux.sh). Il te demande (dans ton explorateur de fichiers si zenity / kdialog est présent) où installer l'extension, télécharge la dernière version, puis te guide pour Chrome / Chromium / Brave / Edge. Pour Firefox il vérifie ton profil et l'édition (mode développeur), te demande l'accord, puis installe l'extension. Aucun sudo, rien n'est écrit hors de ton dossier personnel. Firefox « release » refuse de façon permanente toute extension non signée : le script prépare alors un chargement temporaire, ou utilise Firefox Developer Edition / Nightly / ESR pour une installation permanente.

Firefox, iPhone, Android ?

Android : l'application APK. iPhone : la version web, à ajouter à l'écran d'accueil.
